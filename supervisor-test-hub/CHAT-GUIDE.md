# Керування тестами в Telegram

Усі адміністративні дії доступні тільки Telegram ID зі списку `ADMIN_TELEGRAM_IDS` і тільки в приватному чаті з ботом. Вебпанель залишається доступною та використовує ті самі тести й результати.

## Основні команди

- `/admin` або `/start` — меню з кнопками та продовження незавершеної дії.
- `/newtest` — створити тест крок за кроком.
- `/library` — переглянути, редагувати, скопіювати або архівувати тести.
- `/importtest` — вставити JSON тесту, за потреби кількома повідомленнями, перевірити й зберегти.
- `/assign` — обрати тест, учасників, дедлайн, спроби, виправлення та сповіщення.
- `/team` — імена, Telegram @username і робочі позначки / зміни; змінити робочу позначку.
- `/results` — результати та розбір відповідей із тегами учасників.
- `/cancel` — скасувати поточну чернетку або незавершене призначення.
- `/tests` — власні призначені тести, підготовка і проходження.

## Що писати в поля

**Опис тесту** — короткий вступ до всього тесту. Наприклад: «Перевірка стандартів комунікації з клієнтами. Перед початком повторіть правила та приклади». Опис можна пропустити.

**Пояснення після відповіді** — пояснення, яке бот покаже після неправильної відповіді. Необов’язкове.

**Матеріал перед тестом** — правило, приклад або власний виклад зі сторінки Confluence. До 3000 символів на запитання. Якщо підготовка ввімкнена, матеріал потрібен до кожного питання.

**Посилання на джерело** — повне HTTPS-посилання на Confluence або інше джерело, необов’язкове. Бот не завантажує та не переказує сторінку: текст матеріалу адміністратор додає сам. Права доступу до самого Confluence визначає Confluence.

## Як створити тест у чаті

1. Надішліть `/newtest`.
2. Вкажіть назву, короткий вступ і прохідний відсоток.
3. Надішліть питання.
4. Надішліть варіанти одним повідомленням: кожен із нового рядка, без нумерації.
5. Позначте правильні відповіді цифровими кнопками з прапорцями та натисніть «Готово».
6. Вкажіть бали, пояснення після відповіді, матеріал перед тестом і посилання.
7. Додайте інші питання. У перегляді можна редагувати вибране питання.
8. Перевірте чернетку та натисніть «Зберегти тест».

Нові тести в майстрі та вебредакторі за замовчуванням мають увімкнену підготовку; її можна вимкнути в чернетці/редакторі. Збережений тест з’являється і в чаті, і у вебпанелі. Тест, який уже призначали, редагується через копію для збереження історії відповідей.

## Як працює підготовка

Для тестів з увімкненою підготовкою оператор спочатку бачить матеріали до всіх питань у випадковому порядку. Перехід оновлює текст і кнопки в тому самому повідомленні; завершення підготовки та початок тесту також використовують цю картку. Кнопка джерела відкриває додане посилання. Після перегляду всіх карток можна розпочати тест або повторити матеріали знову.

Підготовка не створює оцінювану спробу і не витрачає ліміт спроб. Місце зупинки зберігається окремо для кожного призначення. Випадкова вибірка запитань для оцінюваного тесту формується окремо; навіть якщо тест бере лише частину питань, підготовка охоплює всі матеріали.

Для старих тестів підготовка початково вимкнена. Поточні активні оцінювані спроби продовжуються як раніше. Завершена підготовка зараховується для наступних спроб того самого призначення; оператор може повторити її кнопкою.

## Призначення й теги

Після `/assign` оберіть тест та учасників кнопками. Імена супроводжуються Telegram-тегами й робочими позначками. Дедлайн вводиться за Києвом: `29.10.2026 18:00`. Призначення та повідомлення створюються тільки після «Підтвердити призначення».

Робочу позначку можна змінити через `/team`. Telegram @username оновлюється з профілю при повідомленні оператора боту; бот не змінює сам Telegram-профіль. Якщо username відсутній, залишаються ім’я та робоча позначка.

## Приклад JSON з матеріалом

```json
{
  "title": "Стандарти сервісу",
  "description": "Повторення правил комунікації з клієнтами",
  "pass_percent": 80,
  "draw_count": 0,
  "learning_enabled": true,
  "questions": [
    {
      "question": "Як варто спілкуватися з клієнтом?",
      "options": ["Коректно й доброзичливо", "Агресивно"],
      "correct": [0],
      "points": 1,
      "explanation": "Коректність і повага є основою якісного сервісу.",
      "learning_text": "Під час роботи з клієнтом зберігайте стриманість, говоріть коректно та не допускайте образ.",
      "source_url": "https://example.com/service-rules"
    }
  ]
}
```

Замість прикладу адреси додайте своє посилання. У JSON індекси `correct` починаються з нуля; у покроковому майстрі можна писати літери або номери від 1. Імпорт без `learning_enabled` зберігається з вимкненою підготовкою. JSON-файли як вкладення поки не підтримуються — вставляйте текст або використовуйте вебпанель.

## Технічні деталі

Чернетки та блокування обробки зберігаються в новій таблиці `th_admin_chat`. Матеріали — у `th_question_learning`, налаштування підготовки — у `th_test_learning`, прогрес підготовки — у `th_learning_progress`. Таблиці створюються ідемпотентно при першому використанні відповідних функцій. Наявні оцінки й таблиці відповідей не мігруються.

Одна незавершена адміністративна дія на одного адміністратора. Старі кнопки чернетки не змінюють новий стан. Повторно доставлений Telegram update не створює повторного призначення чи тесту в перевірених сценаріях.

Збірка: `node build.mjs`. Перевірки: `node verify.mjs` і `node verify-chat.mjs`. Тести використовують тимчасову SQLite в пам’яті та імітують Telegram API — реальні повідомлення не надсилаються.

## Вибір відповідей і відкладені питання (3.4)

Варіанти в тексті пронумеровані. Під ними — кнопки `1 ◻️  2 ☑️  3 ◻️  4 ☑️`, «Відповісти пізніше» та «Наступне питання». Для 5–6 варіантів кнопки розміщено у два рядки. В останньому питанні кнопка називається «Завершити тест».

Для кількох правильних відповідей можна позначити кілька прапорців. Для одного правильного варіанта новий вибір замінює попередній. Бали нараховуються після «Наступне питання», а не під час позначення.

«Відповісти пізніше» переносить поточне питання в кінець списку. Воно повернеться після інших питань. Вибір на ньому очищається, бали не змінюються. Останнє питання необхідно завершити.

Той самий формат кнопок працює для позначення правильних відповідей у майстрі створення тесту. Навчальні картки редагуються на місці. Якщо повідомлення видалене або Telegram забороняє його редагування, бот може створити нове для продовження. Старі повідомлення автоматично не видаляються.
